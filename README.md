# متجر مؤسسة حلا الأجاويد للحلويات | HALA ALAJAWEED

متجر إلكتروني تجاري فاخر ومتكامل ولوحة تحكم إدارية عربية لمؤسسة حلا الأجاويد للحلويات، مبني بأحدث معايير **Next.js App Router**، **TypeScript**، **Tailwind CSS**، قاعدة بيانات سحابية **MongoDB Atlas**، وتخزين سحابي للصور عبر **Cloudinary**.

---

## 🌟 أبرز المميزات والخصائص

1. **هوية بصرية فاخرة وأصيلة**:
   - ألوان الهوية: العنابي الملكي (`#682D43`)، العاجي الدافئ (`#FAF6F0`)، والذهب الملكي (`#C5A059`).
   - الخط العربي المعتمد: **تجوال (Tajawal)** بكافة أوزانه من 200 إلى 900.
   - حركة أقسام سلسة وانسيابية من اليسار إلى اليمين ببطء، وتصميم متجاوب 100% مع الهواتف الذكية والأجهزة اللوحية.

2. **تجربة إتمام طلب فائقة السهولة (Frictionless Checkout)**:
   - **رقم الجوال فقط إجباري** لإتمام وتأكيد الطلب لتسريع العملية ومنع فقدان العملاء.
   - باقي الحقول اختيارية مع قيم افتراضية ذكية.
   - صفحة شكر واحتفال مخصصة بعد إتمام الطلب مباشرة برقم وكود الطلب، وزر نسخ الكود، وإرسال الفاتورة بنقرة واحدة عبر واتساب.

3. **متابعة حالة الطلب برقم الجوال**:
   - متابعة مباشرة لمراحل تجهيز وتوصيل الطلب بإدخال رقم الجوال فقط دون الحاجة لحفظ أو كتابة كود الطلب.
   - دعم عرض أحدث طلب مع إمكانية التنقل بين كافة الطلبات السابقة المسجلة برقم الجوال.

4. **لوحة تحكم إدارية متكاملة (`/admin`)**:
   - إحصائيات حية لحجم المبيعات والطلبات الجديدة والمكتملة.
   - إدارة كاملة للمنتجات والأقسام، رفع الصور مباشرة من الجهاز، وتحديد أسعار القطاعي والجملة.
   - شريط إعلاني علوي متحرك يمكن التحكم بسرعته ومحتواه وحجم الشعار مباشرة من لوحة التحكم.
   - التحكم الكامل في أرقام التواصل، الفروع وعناوينها، روابط التواصل الاجتماعي، وأكواد الخصم الترويجية.
   - تغيير اسم المستخدم وكلمة المرور الخاصة بالإدارة بكل سهولة وأمان.

## 🚀 التثبيت والتشغيل المحلي

### 1. تثبيت الحزم:
```bash
npm install
```

### 2. إعداد متغيرات البيئة:
أنشئ ملف `.env.local` مسترشداً بالملف التوضيحي `.env.example`:
```env
# MongoDB Atlas
MONGODB_URI=mongodb+srv://...

# Cloudinary
CLOUDINARY_URL=cloudinary://...
CLOUDINARY_CLOUD_NAME=...
CLOUDINARY_API_KEY=...
CLOUDINARY_API_SECRET=...

# Admin Authentication
ADMIN_USERNAME=admin
ADMIN_PASSWORD=your_secure_password
JWT_SECRET=your_jwt_secret_min_32_characters

# Public Config
NEXT_PUBLIC_APP_URL=http://localhost:3000
NEXT_PUBLIC_WHATSAPP=+966546002435
NEXT_PUBLIC_STORE_NAME=حلا الأجاويد
```

### 3. التشغيل في بيئة التطوير أو الإنتاج:
```bash
# تشغيل التطوير
npm run dev

# بناء نسخة الإنتاج
npm run build

# تشغيل خادم الإنتاج
npm start
```

## 🔒 الأمان والحماية (Security)
- جميع المفاتيح وكلمات المرور وسلاسل الاتصال بقواعد البيانات معزولة داخل ملف `.env.local` المحمي والذي تم استثناؤه تلقائياً في `.gitignore` لمنع تسريبه.
- تشفير كامل للجلسات وكلمات المرور باستخدام خوارزميات التجزئة `bcrypt` و `jose` (JWT).
- تحقق صارم خادمي (Server-side validation) لجميع المدخلات والأسعار ومطابقة الشروط.
